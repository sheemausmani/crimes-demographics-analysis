# Crime and Demographics in Tower Hamlets
S. Usmani | May 2026
# Overview
This project explores patterns in crime and stop-and-search activity in Tower Hamlets, London, using publicly available data from Police.uk.\
\
The analysis investigates two questions:
- Are certain age groups associated with different categories of stop-and-search activity?
- What is the relationship between recorded crime and stop-and-search activity across different locations?
\
The project combines data cleaning, exploratory data analysis, k-means clustering, and geographical visualisation to investigate these questions.

# Data
The analysis uses:
    - Police.uk stop-and-search data
    - Police.uk crime/outcomes data
    - Lower Layer Super Output Area (LSOA) boundary data from the Office for National Statistics

The datasets are subject to their original licences. See DATA_LICENSES.md for licensing and attribution information.
